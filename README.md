#Intelligent SMS Spam Detection

Intelligent SMS Spam DetectionThis project is an AI-powered Natural Language Processing (NLP) pipeline that automatically classifies SMS messages as legitimate ("Ham") or unwanted ("Spam"). 
it focuses on highly efficient text classification and strict precision to prevent filtering real messages.
Key Technologies & Features:Algorithm: Uses a Multinomial Naive Bayes classifier optimized for text data.NLP Pipeline: Implements robust text preprocessing, including URL filtering, stop-word removal,
and TF-IDF vectorization to convert raw text into processable numerical data.Dataset: Trained and evaluated on the UCI SMS Spam Collection consisting of 5,572 labeled messages.Performance Highlights:High Accuracy: Achieved 96.95% accuracy on unseen test data.Zero False Positives: Reached 100% Spam Precision, successfully catching spam without ever incorrectly blocking a single legitimate message.
